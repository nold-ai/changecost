# Support

ChangeCost is an unreleased research-stage project. There is no supported product
installation or service-level agreement yet.

Use repository issues for reproducible tooling problems or scoped proposals.
Include the commit, command, tool versions, expected result, and redacted output.
Do not attach private session files, prompts, credentials, or billing exports.

For private contact use hello@noldai.com. Security reports follow
[SECURITY.md](SECURITY.md); community concerns follow
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
