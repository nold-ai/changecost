## Context
The unchanged admission authorizes exactly one frozen source and partial request/category diagnostics. It denies reconstructed totals, learning and automatic binding. The runnable outcome is an explicit selected-file attachment shown beside an unchanged before-work estimate.

## Decisions
Use one canonical validated read result shared by core import and Sessions.observe_codex. Reuse the existing canonical fact projection and keep pending core templates private. The session layer receives no raw IDs, path, prompts or Evidence record metadata. Resolve profile and expected SHA from the packaged admission; this convenience grants no admission.

One Sessions owner stores one safe JSON snapshot and one immutable link/event per session. Quantities remain JSON integers, including the existing 4096-digit boundary, never SQLite INTEGER counters. Same snapshot can be explicitly linked to two sessions without duplicate facts. Exact retry allocates no event. Conflicting repository, facts, provenance or link rejects atomically.

Recognize exact v1/v2 schema. Read v1 without writes and continue manual operations on either. Before native writes, check session existence read-only, validate the source through the existing boundary, then recheck under BEGIN IMMEDIATE. Decide migration only after the lock. Migrate v1 and compare/insert snapshot/link/event in one transaction. Retain the committed bootstrap publication and no-clobber behavior.

Native diagnostics have their own nonmanual authority and category units. Manual forecast/measurement/error fields retain their meanings. Native-only attachments have unknown total/error and an explicit native-partial learning exclusion; independent manual totals still retain manual authority. Show/history read only stored data.

## Risk-first checkpoint
Projection drift and migration damage are the critical assumptions. Existing native importer tests must preserve exact serialization, first provenance and replay. Focused populated-v1, conflict/rollback and concurrent attach tests must preserve old rows/event IDs and reject before source-derived writes. Parent preflight reports the actual approved source produces 16 requests and 96 facts; independent real-source demonstration remains a parent obligation after source freeze.

## Risks and rollback
Normal local SQLite filesystem semantics only. No new power-loss/network guarantee. Back up the database with no writer before first native attachment. An old binary refuses v2; rollback after migration requires restoring that pre-upgrade backup. Removing the command alone does not revert the schema. There are no paid calls. Broader native totals/learning and full assurance remain separate.
